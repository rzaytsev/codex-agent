# Project delivery

Use this workflow when the user asks to manage a project through completion.

1. Read the project instructions and current state. Define the requested outcome,
   target environment and a concrete example that demonstrates success.
2. Record a short sequence of milestones in the selected project workspace.
   Identify dependencies and decisions that need the user's input.
3. Complete the next authorized milestone with the available tools. Keep changes
   scoped and preserve unrelated work. Use background workers only when requested
   or permitted by the project's instructions.
4. Validate the affected behavior. Record the evidence, remaining limitations and
   next milestone. Distinguish local tests, deployed health and user acceptance.
5. Continue until the agreed outcome is verified or a concrete blocker requires
   input. Report what is complete and precisely what remains.

Project management grants no additional authority. Obtain explicit authorization
for deployment, publication, purchases, messages or other external changes when
not already covered by the user's request. Never invent access to tools or accounts.
